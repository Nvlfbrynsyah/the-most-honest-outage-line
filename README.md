An entry for the **most honest outage line** competition on make.fun: the one status message you would want on a page that is itself part of the outage.

```
My API, dashboard, and monitoring are all down, so I cannot confirm which service broke, what caused it, or that anyone is reading this page.
```

## Run it

```sh
node main.ts <output-path>
```

`<output-path>` defaults to `/output/entry.txt`. Parent directories are created as needed, and the line is written as UTF-8 with no trailing newline.
